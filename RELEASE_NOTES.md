# ARGUS V26.10.1 Beta 1

The first calendar-versioned beta packages the current React workspace, visual research workflows and integrated media tools.

- Typed data and tool nodes, nested groups, verification, tags and traceable connections.
- Multi-provider username, email and phone discovery; separate profile deep research and search profiles.
- Project autosave, archives, execution queue, source details and report inclusion.
- Image cropping, graphical video time/area cropping, compatible video previews and CPU frame fusion.
- German/English controls, integrated VPN configuration and searchable/exportable logs.
- Group disclosure preserves selection and reverses untouched automatic placement. Tool execution precedes the title in details. Autosave no longer shifts the heading.
- General product README with current synthetic screenshots.

Version: `26.10.1-beta.1`; tag: `v26.10.1-beta.1`.

See `docs/validation-beta1.md` for checks and deployment-dependent limits. Upstream licenses apply; see `THIRD_PARTY.md`. This beta does not certify external-provider availability or a target host's VPN configuration.
